# Design references and provenance

## Current layout

The current templates, stylesheet, and navigation are written for Jie Hu's website. The visual structure follows the user's requested reference:

- Huiyuan Wang: https://huiyuan-wang.github.io/
- White academic layout, persistent profile sidebar, a concise introduction, and a news list.
- Reference viewed November 18, 2026.

The current site is built with Python, Markdown, YAML, and Jinja2. It does not run Jekyll and is not an unmodified AcademicPages distribution. No biography, news claims, publications, portrait, or other personal assets from the reference website are copied into this site.

## Previous layout

Earlier versions adapted the v3 layout in https://github.com/lx10077/lx10077.github.io, under the MIT license. Its original notice is preserved in `LICENSE`. That layout's stylesheet and navigation have been replaced in the current version.
